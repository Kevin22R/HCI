# Uniautónoma Fest 2026

Plataforma web promocional para el festival universitario de la Corporación Universitaria Autónoma del Cauca.

**Fecha del evento:** 19 al 23 de octubre de 2026  
**Ubicación:** Popayán, Cauca, Colombia

## 🎨 Diseño Premium

La propuesta de rediseño supera a la competencia con:
- **Hero corto** vs pantalla entera de naves - información esencial en 5 segundos
- **Tarjetas** vs lista simple - mejor legibilidad y jerarquía visual
- **Comparación visual de kits** en 3 columnas vs lista - precios alineados, clara a un vistazo
- **Navegación móvil útil** (3 botones siempre visibles) vs menú hamburguesa que oculta todo
- **Paleta premium** (crema/verde noche/azul) vs cian neón y fondo oscuro - se ve como festival universitario de ciudad, no videojuego
- **Tipografía elegante** (Fraunces + Outfit) vs Archivo - más legible y profesional
- **Mapa simple** con links a Google Maps vs widget complejo - más claro y funcional
- **Bloque "Ahora en la semana"** - muestra el próximo evento según hora Colombia, no solo una lista estática
- **Tabs con scroll horizontal snap** en móvil - mejor UX que lista larga
- **Sin efectos HUD/scanlines** - diseño limpio, premium y fácil de leer

## 🛠 Tecnologías

- **React 18** con TypeScript
- **Vite** como bundler
- **Tailwind CSS** para estilos
- **Google Fonts**: Fraunces (títulos), Outfit (interfaz)

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
