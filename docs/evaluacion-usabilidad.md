# Evaluación de usabilidad

## Tareas y subtareas

| Tarea | Subtareas | Total subtareas |
|-------|-----------|-----------------|
| T1. Encontrar la programación del festival | 1. Abrir el menú; 2. Seleccionar “Programación”; 3. Visualizar la lista de actividades | 3 |
| T2. Consultar las actividades de un día determinado | 1. Seleccionar un día; 2. Ver actividades filtradas; 3. Identificar al menos una actividad | 3 |
| T3. Identificar horario y lugar de una actividad | 1. Abrir una tarjeta; 2. Leer horario; 3. Leer lugar | 3 |
| T4. Consultar componentes y precio de un kit | 1. Ir a “Kits”; 2. Seleccionar un kit; 3. Leer componentes y precio | 3 |
| T5. Seleccionar un kit y modificar la selección | 1. Seleccionar componentes; 2. Cambiar talla; 3. Quitar un componente o limpiar selección | 3 |
| T6. Completar formulario y corregir un dato inválido | 1. Ir a “Inscripción”; 2. Llenar campos; 3. Enviar con un dato inválido; 4. Corregir el dato; 5. Confirmar envío | 5 |
| T7. Encontrar la sección de ayuda | 1. Abrir el menú; 2. Seleccionar “Ayuda”; 3. Leer una pregunta frecuente | 3 |

Total de subtareas definidas: 23.

## Fórmulas

- Porcentaje de efectividad = (número de subtareas realizadas × 100) / número de subtareas definidas.
- Porcentaje de eficiencia = (tiempo estimado por tarea × 100) / tiempo empleado.
- Satisfacción = suma de las calificaciones obtenidas / número de preguntas respondidas.

## Preguntas de satisfacción (escala 1 a 5)

1. ¿La navegación fue clara?
2. ¿La información fue fácil de encontrar?
3. ¿Los mensajes de error fueron comprensibles?
4. ¿El formulario fue fácil de completar?
5. ¿La página se ve bien en tu dispositivo?

Satisfacción = suma de calificaciones / número de preguntas respondidas.
