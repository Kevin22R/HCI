# Instrucciones para ejecutar y comprobar

## Requisitos
- Node.js 18 o superior
- npm

## Ejecución
```bash
npm install
npm run dev
```
Abrir http://localhost:5173

## Compilación
```bash
npm run build
npm run preview
```

## Comprobación rápida de funcionalidades
1. Portada: verificar contador regresivo.
2. Programación: filtrar por fecha y categoría.
3. Kits: seleccionar componentes, cambiar talla, limpiar selección y revisar total.
4. Inscripción: enviar formulario vacío para ver validaciones; corregir y confirmar.
5. Ayuda: abrir “Ayuda” y revisar FAQ.
6. Panel admin: ver órdenes y estadísticas.

## Notas
- Los datos se guardan en localStorage del navegador.
- Los pagos son simulados y no requieren backend.
